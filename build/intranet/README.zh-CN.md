# Magpie 内网精简版：离线体积验证包

解压后运行 magpie.exe。请保留 runtime/bun.exe 和 .portable。
这是源码构建的试验版，不会替换已经运行的官方 Magpie。
配置保存在程序旁的 data 目录。本包不含真实账号、密钥或用户配置。

运行前提：Windows x64，系统已经安装 Microsoft Edge WebView2。
本包附带 Bun 1.4.2 插件运行时，不包含 WebView2 的离线安装程序。
供应商授权、模型发现和推理仍需要连接其业务服务；“离线”指应用和
插件运行时不需要在线下载安装，并不意味着模型可以离线推理。

裁剪：资源库的页面、API、同步及 MCP/Skills/指令分发；会话历史页面；
通用脚本中间件、OTel、搜索、工具、预热模块的内置注册和前端资源；
演示视频；HEIC 自动解码。常用图片格式仍按原网关逻辑处理。
这些模块的部分共享后端类型仍因原版的交叉依赖留在程序中，不能将
“功能不可用”理解成所有相关 Go 代码都已经物理移除。

关闭：公网使用统计、插件评分及热度、赞助供应商、官方更新、更新说明、
公共模型目录刷新、汇率在线刷新、公共状态查询、Bark 通知、云同步、
Agent 自动升级及安装下载。使用内置模型目录及离线汇率回退。

内部市场固定地址：
  目录：http://172.21.0.177/magpie/plugins/registry.json
  npm 元数据：http://172.21.0.177/npm
  插件制品：http://172.21.0.177/magpie/plugins/dist
  插件说明：http://172.21.0.177/magpie/plugins/readmes/<key>.md
  图标：http://172.21.0.177/magpie/icons?url=<encoded-url>
服务器部署尚未包含在本试验中，目录不可达时显示内部缓存或空列表，
不会切换到公共社区目录。公网发现与资源下载的公网回退已阻断。

本试验暂时关闭网络插件安装，只支持已打包完整依赖的本地插件目录：
  magpie.exe plugin add D:\path\to\bundled-plugin
原因：只改 npm 默认 registry 仍会被包内的远程依赖和下载地址绕过。
内部制品的完整依赖、版本及校验协议接好后才能启用一键安装。
供应商插件自身具有网络能力，仍须在发布到内网前审查其业务地址。
