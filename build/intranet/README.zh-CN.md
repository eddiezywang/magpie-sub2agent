# Sub2Agent 内网版

解压后运行 Sub2Agent.exe。请保留 providers 和 .portable；若包含 runtime/bun.exe，也请保留。
这是源码构建的试验版，不会替换已经运行的官方 Magpie。
配置保存在程序旁的 data 目录。本包不含真实账号、密钥或用户配置。

运行前提：Windows x64，系统已经安装 Microsoft Edge WebView2。
本包附带 Bun 1.4.2 插件运行时，不包含 WebView2 的离线安装程序。
供应商授权、模型发现和推理仍需要连接其业务服务；“离线”指应用和
完整包的插件运行时不需要在线下载安装，并不意味着模型可以离线推理。
轻量包首次启动插件需要连接行内网络或 VPN，自动下载并校验运行时后缓存，
无需 Node.js/npm，也不会回退到公网下载。下载失败请检查网络后重试或重启应用。

保留：会话历史页面及其阅读、搜索、恢复和导出交互。
裁剪：资源库的页面、API、同步及 MCP/Skills/指令分发；
通用脚本中间件、OTel、搜索、工具、预热模块的内置注册和前端资源；
演示视频；HEIC 自动解码。常用图片格式仍按原网关逻辑处理。
这些模块的部分共享后端类型仍因原版的交叉依赖留在程序中，不能将
“功能不可用”理解成所有相关 Go 代码都已经物理移除。

关闭：公网使用统计、插件评分及热度、赞助供应商、官方更新、更新说明、
公共模型目录刷新、汇率在线刷新、公共状态查询、Bark 通知、云同步、
Agent 自动升级及安装下载。使用内置模型目录及离线汇率回退。

插件由管理员统一维护和发布。插件广场连接失败时显示原因、重试入口和
已保存目录，不会切换到公共社区。也可离线导入完整插件文件夹：
  Sub2Agent.exe plugin add D:\path\to\bundled-plugin
内网发布的完整离线包支持一键安装、版本与摘要校验；不在线下载外部依赖，
不运行安装脚本。服务地址由应用维护，无需用户配置。
供应商插件自身具有网络能力，仍须在发布到内网前审查其业务地址。

已接入 CodeBuddy、WorkBuddy 企业及 Trae 企业的私有认证与请求适配，
沿用 Magpie 供应商及账户交互。保留 Codex、Claude 和自定义供应商。
默认网关端口 8989，与原版 Magpie 的数据和实例隔离。
尚未完成：内网插件服务器部署及完整真实账号验证。
插件 > 内置 > 埋点上报：一个开关统一控制应用运行与用量统计。
不上传对话正文。发送失败时保留待发统计，网络恢复后自动补传；关闭后
暂停采集和发送、保留已保存队列。无需配置服务地址或上报方式。
本包为内部试用构建，不作为正式版。

源码、构建入口及模块说明位于 magpie-intranet 工作树：
  build/intranet.ps1
  docs/intranet-build.md
