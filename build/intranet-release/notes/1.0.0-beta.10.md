### 用量概览

- 已配置的 TIG、CIB 智汇通 API Key、WorkBuddy 企业和 WorkBuddy CIB 可在同一面板切换。每个供应商有「用量」「活跃度」「使用详情」三个视图。
- 活跃度提供每日热力图、每周与累计趋势、Token 峰值和连续使用天数。使用详情按时间和模型展示用量，可以切换模型图例和查看适用系数。
- CIB 智汇通只统计当前网关的 Token，支持 K、M、B 和近 7 天、近 30 天折线。

### 额度和积分

- TIG 智谱可切换 API Key，分别查看五小时和周额度窗口。正常请求中的上游额度 429 用于确认恢复时间。窗口或数据覆盖不足时，额度比例留空。
- WorkBuddy 企业分别展示 MaaS 估算积分和逐请求回传积分。WorkBuddy CIB 按账号显示上游额度和可用的刷新时间。
