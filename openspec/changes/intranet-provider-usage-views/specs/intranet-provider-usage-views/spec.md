## ADDED Requirements

### Requirement: 按配置切换供应商与统计视图

内网「用量 → 概览」SHALL 在单个供应商面板展示已配置的 TIG、CIB 智汇通 API Key、WorkBuddy 企业和 WorkBuddy CIB。每个供应商 SHALL 提供用量、活跃度、使用详情。面板 SHALL 保留原生网关概览位置和交互。

#### Scenario: 部分供应商未配置
- **WHEN** 仅已配置 TIG 和 WorkBuddy 企业
- **THEN** 只出现这两个供应商页签，切换时同一位置显示当前内容

#### Scenario: 没有配置或数据暂时缺失
- **WHEN** 四个供应商均未配置
- **THEN** 隐藏供应商面板并保留网关概览
- **WHEN** 已配置的供应商暂无数据或查询失败
- **THEN** 保留页签并区分无记录、查询失败和真实零值

### Requirement: TIG 按 Key 观察窗口

TIG 智谱渠道 SHALL 复用真实请求的上游 429 识别 5 小时和周额度恢复时间，并按实际 Key 独立保存。用户 SHALL 能用名称或脱敏标识切换启用 Key。系统 MUST NOT 暴露密钥或主动发请求来耗尽额度。

#### Scenario: 上游明确给出两把 Key 的不同窗口
- **WHEN** 两把 Key 分别收到带窗口类型和恢复时间的上游额度 429
- **THEN** 按 Key 和窗口类型独立展示，切换 Key 只读取对应观察结果

#### Scenario: 新窗口只有估算或证据不足
- **WHEN** 恢复后的成功请求支持估算下一窗口
- **THEN** 将估算时间标为估算，区别于 429 明确给出的恢复时间
- **WHEN** 429 仅表示一般限流、窗口含混、时间已经过期或无观测
- **THEN** 不把该事件显示为有效的套餐窗口，未知日期留空

### Requirement: TIG 用量按 Key 核算覆盖

TIG 额度卡 SHALL 使用当前网关账本，按实际使用 Key、原始渠道模型、计费时间和适用费率核算已覆盖积分。智谱 5 小时参考上限 SHALL 使用完整数值 **35,000 积分**。按用户名的服务端汇总 SHALL 单独标记来源。

#### Scenario: 能核算该 Key 的窗口用量
- **WHEN** 已知该 Key 的适用窗口、参考上限和足够的账本及费率覆盖
- **THEN** 显示本地估算积分及其对参考上限的比例，并明确标注为估算

#### Scenario: 存在缺失记录或窗口未知
- **WHEN** 费率或版本、归属 Key、缓存拆分、窗口或历史覆盖存在缺口
- **THEN** 显示已覆盖的估算值及缺失状态，完整额度比例留空
- **AND** 按用户名的服务端积分和近 7 天滚动估算不冒用为该 Key 的套餐周用量

### Requirement: 各供应商保留原始计量口径

CIB 智汇通 SHALL 统计当前网关的 Token 并显示今日、近 7 天、近 30 天和保留账本累计。WorkBuddy 企业 SHALL 标注 MaaS 估算积分。WorkBuddy CIB SHALL 优先展示上游提供的账号已用、总额度和可选的重置原文。

#### Scenario: 智汇通账本有输入、输出及缓存读写
- **WHEN** 计算智汇通 Token 用量
- **THEN** 输入、输出和缓存独立计入一次，使用 K／M／B，推理 Token 不重复相加
- **AND** 页面不显示智汇通积分或额度估算

#### Scenario: WorkBuddy CIB 仅返回重置文本
- **WHEN** 上游返回已用积分、总额度和原始重置时间，缺少起止或时区
- **THEN** 展示上游数值及原始重置时间，其它时间字段留空
- **AND** 多账号额度分别显示，账本中的逐请求实扣与账号额度分别标明来源

### Requirement: 当前网关的活跃度

活跃度 SHALL 使用当前网关账本生成每日热力图、每周趋势、累计趋势、累计 Token、单日峰值、当前和最长连续使用天数。页面 SHALL 省略累计使用时长。

#### Scenario: 日历与连续值
- **WHEN** 用户按供应商查看活跃度并切换每日、每周或累计
- **THEN** 使用同一账本及显示时区，格子和趋势反映实际聚合值
- **AND** 区分已知无用量与历史不可用，累计 Token 的范围明确为当前保留账本

### Requirement: 分模型使用详情

使用详情 SHALL 支持当日、近 7 天、近 30 天。时间序列 SHALL 按供应商、日期和模型聚合，适用时增加 TIG 渠道约束。现有缓存命中统计和适用的低峰口径 SHALL 保持一致。

#### Scenario: 筛选堆叠图
- **WHEN** 用户勾选或取消某个模型
- **THEN** 图表与可见模型合计同步变化，区间总量保持不变

#### Scenario: 计费明细与来源
- **WHEN** 用户展开模型系数表或在允许的计量值间切换
- **THEN** 逐项标注单位、费率出处和适用条件，未知值留空且不合并不同计量单位
- **AND** 没有可用峰谷规则或时间数据时不显示低峰占比
