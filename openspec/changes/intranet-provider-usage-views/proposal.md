## Why

内网版的用量概览将 TIG 说明和智汇通图表纵向堆叠，未配置智汇通时仍会显示零用量。用户需要在同一面板切换已配置的供应商，并分开查看额度、活跃度和按模型的使用详情。额度卡还需要复用 TIG 从网关 429 记录的窗口和 WorkBuddy CIB 上游返回的重置时间。

## What Changes

- 将供应商用量收进一个内网面板，提供 TIG、CIB 智汇通 API Key、WorkBuddy 企业和 WorkBuddy CIB 页签。未配置的供应商隐藏。每个供应商提供「用量」「活跃度」「使用详情」。
- Token 统计以当前网关账本为主。分别标注 TIG 按 Key 的本地估算、WorkBuddy 企业 MaaS 估算以及 WorkBuddy CIB 上游额度和回传扣减。
- 接入 TIG 智谱渠道 429 窗口记录。多 Key 支持切换，分开显示 5 小时和周窗口。已用积分按实际 Key 和原始计费模型估算。有效额度 429 显示 100% 和红色满条。无有效额度 429 且覆盖无法确认时保留参考值和已覆盖用量，百分比留空。
- 复用 WorkBuddy CIB 已有额度查询，显示已用、总额度和上游重置时间原文。智汇通只展示 Token，用 K／M／B 表示。
- 复用日历热力图，补充按日期和模型聚合的数据。使用详情支持当日、近 7 天和近 30 天、堆叠图筛选及模型系数表。活跃度移除累计使用时长。

## Capabilities

### New Capabilities

- `intranet-provider-usage-views`: 供应商用量三视图、额度与窗口来源、当前网关活动及分模型时间序列。

### Modified Capabilities

当前仓库没有相关已归档的 OpenSpec 基线。子系统契约见用量、计费和供应商文档。

## Impact

涉及内网用量插件、GUI 查询接口、账本的分模型聚合、TIG 窗口读取和本地费率计算、WorkBuddy CIB 额度结构。原有全网关概览、请求页、路由和服务端分钟上报协议继续沿用。实施时补充账本与计费回归、Playwright 验收和脱敏评审截图。
