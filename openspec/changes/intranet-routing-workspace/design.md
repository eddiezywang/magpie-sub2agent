## Goals / Non-Goals

**Goals:** 将已确认预览变成可保存配置、可观测真实输出的内网工作台；所有操作与独立页面保持一致；把性能、数据口径和异常显示做成可验证契约。

**Non-Goals:** 新组件库、全局路由策略、自动创建路由组、批量修改所有 Agent、改变已有模型选择规则、修改供应商认证、账单汇总或历史用量补算、持久化曲线、上游 UI 改版。托盘继续使用既有紧凑页面，不强塞双栏工作台。

## Decisions

### 1. 同一文档组合原生模块

增加仅内网可用的 workspace 页面和独立 workspace.js/workspace.css。通过窄的共享入口让 Agent、供应商和路由模块挂载到活动宿主，共用原始 DOM、状态及全局 picker/modal；一个模块同时只有一个活动宿主。离开时归还原页面宿主，维护编辑保护、滚动位置、焦点和 URL。

不复制 renderAgents/renderProviders，不继续使用 iframe，不用隐藏的完整页面作为后台运行的第二实例。相关可见性判断和路由 ResizeObserver/poll 启停改为由活动宿主决定；事件与观察器只注册一次。工作台同时可见的模块不会触发互相 cancelEdit 或清理状态。供应商未保存草稿沿用现有离页确认，不能被刷新或折叠静默丢弃。

首次无显式页面且无可恢复历史时打开工作台；显式深链和用户上次页面优先。独立 Agent、供应商、路由、路由组、Sessions 和设置入口保留。上游发行版及托盘默认行为保持。

替代方案：iframe 的重复加载、焦点刷新、弹层裁切和状态割裂已在预览中显现；复制 UI 会使后续功能漂移，因此采用共享活动宿主。

### 2. Agent 概览与供应商窄栏

概览基于正式 Agent 快照统计同一列表中的接入/未接入数量，未知配置状态独立标记，不伪装成未接入。默认折叠，展开复用完整列表、原生模型菜单、版本、详情、开关与管理入口。操作成功后更新共享状态，失败恢复显示并保留错误反馈。

移除 agentconnections.js 在每行追加的重复 .connection-check 展示：不再同时显示“已接入”和“已配置接入 sub2agent”，不再显示“未配置接入 sub2agent · 接入 sub2agent”第二行。保留必要配置检测能力；未知、配置漂移和失败反馈合并到原生状态/详情，不能通过删除附加行丢失诊断或现有适配能力。单行接入统一使用原生开关和必要的既有适配流程。

“一键全部接入”属于 Agent 页顶部工具区；工作台复用 Agent 模块时出现在展开列表自身的顶部，工作台页面顶部与折叠概览均不增加此按钮。按钮采用原生样式，展示待接入数量；无可操作对象时禁用。候选是完整 Agent 快照中原生可接入、已安装、未接入的对象，不受搜索过滤影响；已接入、不可操作和状态未知项不改写，未知项提示重新检测。点击后固定本批候选，逐个复用原生接入校验/API及必要确认，不创建绕过原流程的强制批量写入接口，不覆盖用户已有模型选择。需要用户处理的项目串行等待既有流程，取消该项目则跳过并继续其余项目。

执行中显示完成进度，禁止重复批量操作并与逐行操作共用 pending 锁。个别失败继续处理其他候选，结束显示成功/失败/跳过数量及项目错误，可只重试失败项；无需对成功项回滚。每次结果按 Agent 身份合并服务器快照，结束后重读配置以刷新两个页面的状态和概览。离页清理 UI 订阅并停止调度尚未开始的项目，已发出的请求正常完成，返回后重新读取真实状态，不因迟到响应恢复旧列表。

桌面以路由为主列、供应商为右栏；空间不足时右栏移到下方。米白点阵、原生浅色路由边框、深色主题 token、像素 S 和供应商图标全部复用。折线桌面目标宽 220px，窄屏按可用空间缩放；展开后手机仍能查看曲线和数值。编辑器使用现有顶层弹层，不受右栏宽度裁切。TIG/CIB 使用现有 tig-color/cib-zht 资产和一致名称。

### 3. 路由策略作用于一个明确的 Agent

工作台维护显式目标 Agent，并从该 Agent 的可编辑主模型字段读取实际选择。目标可以在本次页面访问中保留；默认采用第一个已接入且支持主模型选择的 Agent，显示其名称，无合格目标时显示提示。已有直接模型配置显示原值，不伪装成某个策略。

可选项仅来自正式 groups 数据中已有的、带受支持 TemplateKind 的预定义组，使用真实组引用和名称；不把模板建议当成已创建的组。已被手动编辑并移除 TemplateKind 的组仍可显示为当前值，但不作为快捷预定义选项。不可用组禁用并说明原因。无组时进入路由组管理配置。

切换复用原生 Agent 模型配置流程（包括必要的既有确认和校验），不新增全局配置键。只修改选定 Agent 的主模型字段，不自动接入未接入 Agent、不覆盖其他模型角色。保存期间禁用重复提交；以服务器返回的 Agent 快照作为最终状态。失败保留旧值；目标切换或异步刷新时按 Agent 身份关联响应，旧响应不能覆盖新目标。编辑入口执行 show('groups')，遵守草稿保护并允许返回工作台。

### 4. 工作台统计独立于 Sessions 的现有曲线

复用 liveRow.observe 的内容增量和实际路由归属，增加内存中的独立 throughput meter。不得从 HTTP/SSE 总字节、请求数或请求结束时总 token 推导实时速度，也不得直接把各会话当前速度相加作为唯一数据源。已有 /api/speeds、curveSpan、curveSmooth 和 Sessions 展示保持兼容。

每个输出片段带实际 provider/model、agent/session；会话键为 agent+session，同名会话不合并。无 session 的输出仍进入总量、供应商及模型，并归入“未识别会话”。同一会话切换模型时按片段原始归属入桶；路由重试只统计实际交付 Agent 的输出，未交付的失败尝试不重复计算。缓存输入和思考是否可见不改变原则：仅采集已交付的模型输出内容，UI 标记为“估算输出 token/s”。

使用服务端秒时钟的 180 个已完成秒桶；最近未完成秒不参与显示。实时值为最后 5 个完整秒（不足的桶补零）的输出估算 token 总和除以 5；曲线每点为该秒输出 token 数除以 1 秒。空闲为零，缺测为 null。初次启动前的时间为 null。每条序列的峰值是进程启动以来该序列已记录的五秒均值最高值；总峰值从总序列单独计算。重启重置并返回 epoch；被淘汰的维度重建时返回新的 startedAt，不宣称保留完整生命周期峰值。

转换沿用 liveRates 已学习的模型换算率，并在样本入桶时固定估算值，避免后续换算率改变已展示历史。未知换算率的内容可保留形状，但不得当作 token 数；受影响秒标记未校准，聚合序列该秒不可显示成精确总量。状态区分 ok、partial、uncalibrated；只有全部参与贡献可换算时才显示数字总量，部分未知时以“待校准”及说明展示，已校准的独立维度仍可显示。不把完成时最终 usage 校正一次性灌入当前秒制造尖峰。

### 5. 查询接口、边界和生命周期

新增 GET /api/gateway/throughput，GUI handler 获取真实网关所有者数据；同机所有者转发遵循 OwnerTrace 的 loopback、身份和访问限制。没有可用所有者或旧版本不支持时返回明确 unavailable，不返回全零伪装空闲。接口不得触发供应商请求、读取会话文件或要求开启会话内容录制。

建议响应契约（实现时固定字段并补接口测试）：
- version: 1；epoch：进程代际；asOf：最后完整秒时间；intervalSeconds: 1；windowSeconds: 180；smoothSeconds: 5。
- status: ok/partial/unavailable；total；providers/models/sessions 数组。
- 每条序列：稳定 id、显示标签、startedAt、calibration、current/peak（未知为 null）、points（180 个 number 或 null）；会话附 agent，模型附 provider，避免同名碰撞。
- truncated 和 omittedSeries 表示维度超限；错误含可展示的有限原因，不返回凭据、请求内容或绝对路径。

总序列不依赖维度保留。供应商/模型/会话分别最多保留 128/512/256 条，按最后活动淘汰；超限必须显式标记，不能使总量少计。采样热路径只做有界内存写入，不做 I/O、排序或 JSON 序列化；查询在锁外构造响应。曲线不持久化、不发往远程用量收集服务。峰值只为在内存中保留的序列维护。

页面可见时单飞每秒查询；慢请求不重叠，离页/后台停止轮询，恢复时读取服务端窗口。失败保留最后一次曲线并标记中断、最后更新时间，不能继续动画或补假数据；重连以服务端窗口替换，epoch 改变清除旧峰值。禁止用浏览器本地累加替代网关统计。

## Risks / Trade-offs

- [原模块依赖固定页面和全局 view] → 先覆盖宿主切换、编辑保护和单次订阅，再组合页面；不扩大核心脚本体积预算。
- [未知 token 换算率] → 明示估算与未校准，避免把内容字节称为 token；首个模型可能暂时无数字。
- [高并发和高基数会话] → 固定窗口与序列上限、显式截断、独立总量、并发测试和 race 检查。
- [网关由另一进程持有] → 所有者转发和 unavailable 契约，验证旧所有者与超时。
- [预定义组被删除或已改为手工组] → 每次保存服务端校验，不猜测组 ID，不自动创建替代组。

## Migration Plan

1. 提取共享模块挂载入口并回归原页；独立验证后提交、推送。
2. 接入工作台导航、原生操作和 Agent 路由组保存；隔离配置验证持久化与返回。
3. 增加统计器与接口，独立于既有 Sessions；接入 180 秒图表与异常显示。
4. 更新子系统文档及内网打包契约，检查实际打包资产。Playwright 在 Chrome/WebKit、1440/1024/390 宽、浅/深色验证所有保留页；截图仅使用隔离数据，发布至指定评审站点。
5. 每个独立验证阶段在 develop/intranet 提交并推送，记录检查和限制。交付包括可运行内网构建、规格映射、截图和实际数据链路验收记录。

无需数据迁移。回滚时移除内网工作台入口并恢复既有页面宿主；已成功保存的用户模型配置保留，禁止自动恢复旧配置覆盖用户选择。新增统计仅为内存状态，旧版本忽略新增接口。

## Open Questions
