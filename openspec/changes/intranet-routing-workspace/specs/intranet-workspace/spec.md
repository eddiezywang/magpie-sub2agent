## ADDED Requirements

### Requirement: 原生工作台与发行范围
内网主窗口和 Web 管理界面 SHALL 提供名为“工作台”的首页入口，包含 Agent 接入、路由策略、右侧供应商和路由容器底部吞吐量；独立页面及 Sessions MUST 保留。上游发行版和托盘默认行为 MUST 保持兼容。

#### Scenario: 首次进入
- **WHEN** 用户没有显式页面和可恢复的上次页面
- **THEN** 内网主窗口打开工作台；显式深链和有效的上次页面优先于默认页

#### Scenario: 原页导航
- **WHEN** 用户从工作台访问 Agent、供应商、路由、路由组或 Sessions
- **THEN** 对应原生页面可达，返回工作台不遗失已保存配置

### Requirement: 共享原生操作与状态
工作台 SHALL 复用原生模块、API 和状态，一个模块只能有一个活动宿主；MUST NOT 使用生产 iframe、模拟 API 或复制的独立编辑逻辑。

#### Scenario: 跨页面状态一致
- **WHEN** 用户从工作台修改 Agent 模型或保存供应商，然后打开独立页面
- **THEN** 独立页面读取相同实际配置，重新进入工作台保持一致

#### Scenario: 未保存草稿
- **WHEN** 用户编辑供应商尚未保存并尝试离开工作台
- **THEN** 执行原有草稿保护；取消离开后草稿和操作焦点仍可用

#### Scenario: 反复进入
- **WHEN** 用户多次切换工作台和原页面
- **THEN** 观察器和事件不重复注册，未出现重复提交、后台轮询或失效弹层

### Requirement: 紧凑接入概览
Agent 区域 SHALL 默认折叠并从真实快照展示已接入、未接入数量；未知状态 MUST 独立说明。展开 SHALL 展示与 Agent 页一致的内容和适用操作。

#### Scenario: 展开和操作
- **WHEN** 用户展开接入区域并操作模型菜单、详情、开关和管理入口
- **THEN** 内容和行为与原页一致，成功后数量更新；失败不伪装成功

#### Scenario: 读取失败
- **WHEN** 配置状态无法读取
- **THEN** 展示未知或读取失败并提供重试，不静默计为未接入

### Requirement: 统一视觉与供应商窄栏
工作台 SHALL 沿用原生点阵米白底色、路由边框、主题 token、像素图标和控件；供应商 SHALL 保留原生列表、添加、编辑、开关和认证行为，TIG/CIB 名称分别为 TIG-Coding-Plan、CIB-智汇通-APIKEY 并加载原 Logo。

#### Scenario: 添加供应商
- **WHEN** 用户打开右栏添加供应商
- **THEN** 原生入口和图标完整可见，编辑弹层不被窄栏裁切

#### Scenario: 窄屏深色与键盘
- **WHEN** 页面在 390px 宽、深色主题或使用键盘导航
- **THEN** 布局按需堆叠，无页面横向溢出，折叠状态和焦点可辨认，吞吐量曲线和数值仍可查看

### Requirement: 精简 Agent 行接入展示
内网 Agent 页和工作台共用的 Agent 列表 SHALL 移除重复的“已配置接入 sub2agent”“未配置接入 sub2agent”附加行及额外接入按钮，接入操作 SHALL 统一使用原生开关。必要配置检测、适配流程、未知状态和错误诊断 MUST 保留并合并到原生状态或详情。

#### Scenario: 已接入和未接入行
- **WHEN** 用户打开 Agent 页或工作台内展开的 Agent 列表
- **THEN** 每行仅保留统一原生接入状态与操作，不再追加截图中的重复说明及按钮，模型菜单和详情保持可用

#### Scenario: 状态未知或配置漂移
- **WHEN** 配置无法读取或需要适配已有连接
- **THEN** 原生状态或详情说明实际问题并保留重检/适配路径，不因精简展示误判为已接入或删除必要功能

### Requirement: Agent 顶部一键全部接入
系统 SHALL 在 Agent 页顶部工具区提供“一键全部接入”，并在工作台复用时位于展开的 Agent 列表顶部；MUST NOT 放在工作台页面顶部或折叠摘要内。操作 SHALL 基于完整快照，处理已安装、原生可操作且未接入的 Agent，不受搜索过滤影响；已接入、不可操作及未知状态项 SHALL 跳过并说明。

#### Scenario: 按钮位置与候选数量
- **WHEN** 用户打开 Agent 页或展开工作台 Agent 列表
- **THEN** 按钮位于 Agent 内容顶部，显示可接入数量；无候选时禁用，工作台顶部和折叠概览无此按钮

#### Scenario: 批量接入与必要确认
- **WHEN** 用户点击一键全部接入
- **THEN** 系统固定候选列表并逐个复用原生校验、接入及必要确认，保留既有模型选择；取消某项则跳过该项继续其他候选，已接入 Agent 不被重写

#### Scenario: 部分失败及重试
- **WHEN** 批量中部分 Agent 接入失败
- **THEN** 其他候选继续执行，成功项保留，结束展示成功/失败/跳过数量和项目错误，允许仅重试失败项并刷新真实状态及概览

#### Scenario: 重复操作和离页
- **WHEN** 批量正在执行而用户再次操作或离开 Agent 宿主
- **THEN** 共用 pending 锁阻止重复写入；离页停止调度未开始项，已发请求不被伪装撤销，返回后读取真实状态且旧响应不覆盖新列表
