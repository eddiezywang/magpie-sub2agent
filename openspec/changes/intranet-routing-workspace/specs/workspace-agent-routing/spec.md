## ADDED Requirements

### Requirement: 明确单个 Agent 作用范围
路由策略 SHALL 显示当前目标 Agent 和其真实主模型配置；默认选择已接入且支持主模型选择的 Agent。MUST NOT 引入全局策略或隐式批量修改。

#### Scenario: 目标切换
- **WHEN** 用户选择另一 Agent
- **THEN** 界面显示该 Agent 的配置，直接模型不被误标为某个路由组

#### Scenario: 无适用目标
- **WHEN** 没有已接入且支持主模型选择的 Agent
- **THEN** 显示接入或管理提示，不自动接入或修改任何配置

### Requirement: 只选择已有预定义组
快捷路由组 SHALL 来自正式数据中已经存在且具备受支持模板身份的组；不可用项 SHALL 禁用并说明原因，不存在时 SHALL 提供管理入口。

#### Scenario: 缺失和手工组
- **WHEN** 组尚未创建、不可用或已手动编辑移除模板身份
- **THEN** 不自动创建；当前手工组仍显示实际值，但不冒充快捷预定义组选项

### Requirement: 持久化与并发一致性
选择 SHALL 复用原生 Agent 模型保存流程，仅修改目标主模型字段，以服务器快照确认结果；MUST 保留既有确认、校验、错误恢复和原应用数据隔离。

#### Scenario: 保存生效
- **WHEN** 用户为目标 Agent 选择一个可用预定义组并保存成功
- **THEN** 重开页面仍显示该真实组引用；实际请求按该组路由，其他 Agent 与角色字段不变

#### Scenario: 保存失败或组已删除
- **WHEN** 保存请求失败或组在保存前被删除
- **THEN** 显示错误并恢复服务器确认的旧配置，不假装应用成功

#### Scenario: 迟到响应
- **WHEN** 保存期间切换目标或收到较旧刷新响应
- **THEN** 响应按 Agent 身份关联，旧目标结果不覆盖新目标；重复提交被抑制

### Requirement: 管理入口
工作台 SHALL 只提供选择入口，路由组编辑 SHALL 跳转原生路由组页面并保留离页保护。

#### Scenario: 编辑和返回
- **WHEN** 用户点击编辑路由组并完成修改后返回
- **THEN** 使用原生编辑流程；工作台重新读取可选组和实际配置
