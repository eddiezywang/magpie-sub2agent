## Why

Agent、供应商、路由组和实时路由分散在独立页面，缺少一个能查看整体状态并直接操作的首页。已认可的工作台预览需要接入正式配置与真实网关数据，同时保留 Magpie 原生交互和内网版视觉。

## What Changes

- 新增内网版“工作台”页面，以原生路由可视化为主体，组合默认折叠的 Agent 接入区和右侧供应商管理区。
- 移除 Agent 行中重复的“已配置接入 sub2agent / 未配置接入 sub2agent”和额外接入按钮，保留原生状态与开关；在 Agent 页顶部增加“一键全部接入”，工作台复用时位于展开的 Agent 列表顶部，不放在工作台顶部或折叠摘要内。
- 共用原生列表、模型选择、接入开关、供应商编辑及认证；使用同一文档、状态与弹层，替换预览用 iframe 和模拟 API。
- “路由策略”按当前选定 Agent 展示真实配置，仅允许选用已配置的预定义路由组；编辑进入原生路由组页面。
- 复用网关输出采集入口，新增总量、供应商、模型、会话维度的实时吞吐量与独立峰值，保留近 180 秒，每秒更新，实时值使用最近 5 秒平均。
- 保留米白点阵、原生路由容器、像素图标和控件；添加供应商沿用 TIG-Coding-Plan、CIB-智汇通-APIKEY 及原生 Logo。
- 保留独立页面和 Sessions；运行时新增能力仅进入内网发行版，不迁移原应用数据，不改变分钟计费聚合。

## Capabilities

### New Capabilities

- `intranet-workspace`: 工作台原生模块组合、状态同步、视觉、布局及导航。
- `workspace-agent-routing`: 明确 Agent 作用范围的预定义路由组选择、保存和编辑跳转。
- `workspace-throughput`: 网关实时输出统计、180 秒曲线、维度归属、估算与异常状态。

### Modified Capabilities

无已归档的 OpenSpec 基线需要修改。现有子系统契约以 docs/subsystems 下文档及源码为准；本变更与 intranet-retro-visual-refresh 叠加，沿用其视觉与兼容约束。

## Impact

涉及 GUI 导航和生命周期、Agent/供应商共用渲染、routing 插件的挂载入口、网关 live 输出采集及新增吞吐量查询接口。新增代码独立于核心大脚本，遵守现有体积预算，不引入组件库。现有 /api/speeds 与 Sessions 的 120 秒/3 秒平滑语义保持兼容；新接口独立提供工作台的 180 秒/5 秒语义。需要更新 GUI、路由和会话速度相关子系统文档，补充 Go 与 Playwright 验证和脱敏评审截图。
