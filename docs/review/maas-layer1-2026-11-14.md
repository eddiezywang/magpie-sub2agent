# WorkBuddy MaaS operational context — 2026-11-14

The model plugin now advertises at most 256,000 context/input tokens and
32,000 output tokens for MaaS. Discovery metadata is preserved separately.
Smaller capacities remain smaller; mapped MaaS names and unknown non-Auto
MaaS deployments get the working window. Ordinary models and hy4free remain
unchanged. Auto with unknown capacity stays unknown.

Claude Code and Codex use a 224,000-token default compact recommendation
through existing configuration-writing paths, including groups containing
MaaS. Explicit model/provider compact settings, shared compact settings,
full-context preferences and typed windows retain their precedence. Other
agents receive the operational model window and retain their own scheduling.

The earlier upstream experiments accepted ~1,012,890 serialized bytes and
rejected ~1,062,000 bytes for sampled MaaS deployments. A native Claude
summary at ~1,037,025 bytes succeeded. These byte observations do not establish
a universal token cap; 224K is an operational recommendation with headroom,
not a guarantee that arbitrary code, images or escaped tool output will fit.
The separate compact-413-to-hy4free rescue is unchanged.

Native Claude Code test (.27): a 944,681-byte synthetic summary compacted
231,848 estimated tokens to 793 in 30,359 ms on the original GLM MaaS.
Every request returned 200, hy4free was not used, and the resumed original
MaaS turn returned ORCHID-7429. An isolated config used 256K context, 224K
compact and 8K output. The first long prompt exceeded the recommendation and
triggered compact before a normal turn; gradual tool-driven growth was not
tested. .28 adds the 32K default output ceiling, verified via the actual
running catalog and plugin tests; the native test's 8K request is unchanged.

Verification: 18 plugin tests; focused Agent/Provider/Gateway regression set;
real Claude settings output and user override preservation. An unrelated
macOS restart simulation used mixed separators on Windows; fixed and verified
in its own commit. Source commits: 95b8efe, 6be8d99, 87333f3.

The local .28 app uses bundled WorkBuddy 1.0.7. Pricing/usage attribution and
the 413 rescue trigger were not changed. Review artifacts at
